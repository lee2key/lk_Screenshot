# lk Screenshot

Локальная утилита для Windows x64. C# / WPF, системный .NET Framework 4.8. Без сторонних пакетов и сетевых функций. Код написан с нуля, код ShareX не используется.

## Запуск

Откройте `dist/v0.15/lk Screenshot.exe` или ярлык `lk Screenshot.lnk` в той же папке. Рядом оставьте файл `.exe.config`.
При первом запуске открываются настройки. Закройте или сохраните их, чтобы начать захват. Программа остаётся в трее; двойной щелчок по значку открывает настройки, меню содержит захват и выход.

- Print Screen — выделение области основного монитора.
- Shift + Print Screen — весь основной монитор.
- Ctrl + Print Screen — открыть выбранную папку скриншотов в Проводнике; отсутствующая папка создаётся автоматически. Это действие доступно и из меню трея.
- Редактор: стрелка, рамка, карандаш, текст, размытие, обрезка, пять цветов и отмена до 12 действий.
- Enter — сохранить PNG и скопировать изображение в буфер. Esc — закрыть без сохранения. Ctrl+Z — отменить правку.
- Без редактора изображение сразу сохраняется и копируется.
- Папка по умолчанию: системные «Документы» → `Screenshots` (обычно `C:\Users\USERNAME\Documents\Screenshots`). Поддерживается перенаправленная папка «Документы».
- Звуков и уведомлений об успешном сохранении нет. Ошибки показываются отдельно.
- При первом запуске Start with Windows отмечен по умолчанию. Нажатие Save регистрирует текущий exe для запуска при входе пользователя в Windows. Существующий выбор пользователя сохраняется. После переноса exe откройте настройки и нажмите Save с включённым Start with Windows, чтобы обновить путь.

Если клавиши заняты, закройте ShareX/другую утилиту и перезапустите приложение. Если Print Screen открывает «Ножницы», отключите соответствующую функцию в настройках клавиатуры Windows. Приложение не меняет её автоматически.

## Сборка и проверка

`powershell -ExecutionPolicy Bypass -File .\build.ps1`

SDK и загрузка пакетов не требуются: используется компилятор системного .NET Framework.

`& '.\dist\v0.7\lk Screenshot.exe' --self-test test-output`

Самопроверка сравнивает пиксели после 20 последовательных штрихов, отмены, обрезки, размытия и повторного чтения PNG. Проверяются точность координат на снимке 4K, обработка прерванной записи и отображение окон. Итог находится в `test-output/result.txt`. Она не трогает буфер обмена, автозапуск и настройки пользователя.

## Ограничения

Только основной монитор. Нет записи видео/GIF, установщика, цифровой подписи и поддержки смешанного масштаба нескольких мониторов. Размытие визуальное и не предназначено для гарантированного удаления секретных данных. Размер исполняемого файла не отражает потребление памяти: оно требует отдельного измерения на целевой системе. История хранит до 12 действий. Для обычных правок сохраняются пиксели ограничивающего прямоугольника, для обрезки — предыдущий кадр. Расход памяти зависит от размеров правок.

Полный ручной сценарий: освободить клавиши → запустить → закрыть настройки → выделить область → нарисовать стрелку → Ctrl+Z → обрезать → Enter → проверить PNG и вставку в Paint. Повторить с Shift+Print Screen и с выключенным редактором. Проверить Esc и сохранение настроек после перезапуска.

## Качество снимков в v0.8

Редактор рисует каждую аннотацию в координатах исходного снимка и меняет только пиксели под ней. Масштаб окна влияет только на просмотр. Захват передаёт пиксели напрямую в редактор. Размытие обрабатывает выделенный фрагмент, обрезка сохраняет все пиксели, которых касается выделение.

Если буфер обмена занят, копирование можно повторить без второго PNG. При ошибке записи можно выбрать другую папку. Готовый PNG появляется в папке после завершения записи.

## Исправления v0.2

Линия карандаша создаётся до захвата мыши и включения обработки движений. Предварительные фигуры больше не перехватывают попадания мыши. Потеря захвата отменяет незавершённый штрих. Ошибки операций записываются в `lk Screenshot-error.txt` рядом с программой; редактор показывает ошибку вместо немедленного завершения приложения.

В этой версии вручную через окно проверены стрелка, рамка, карандаш, текст (включая ввод через диалог), размытие, обрезка, Ctrl+Z и сохранение PNG на тестовом изображении. Расширенная самопроверка проверяет каждый инструмент, отмену, прерывание штриха и серию из 20 штрихов. Старый пользовательский вылет без его журнала точно не идентифицирован; исправлен обнаруженный риск в обработке начала рисования.

Для диагностики доступны отдельные режимы:

- `lk Screenshot.exe --test-hotkeys` — область на Ctrl+Alt+Shift+7, экран на Ctrl+Alt+Shift+8, папка на Ctrl+Alt+Shift+9. Обычный запуск использует Print Screen / Shift+Print Screen / Ctrl+PrintScreen.
- `lk Screenshot.exe --editor-demo` — редактор с тестовым изображением без захвата экрана. Сохранение пишет только `demo-result.png` рядом с программой, не меняя буфер обмена и пользовательские настройки.

Перед запуском новой версии завершите предыдущую через меню значка в трее. Старые сборки не обновляются во время работы.

## Оформление v0.3

Интерфейс адаптирован к `PieMenu/APP_DESIGN.md`: именованные цвета в `src/Theme.xaml`, фон #2E2E2E, карточки #3B3B3B с радиусом 9, поля и кнопки с радиусом 4, Segoe UI 11 pt, компактные контролы и интервалы 12. Основные действия и выбор инструмента используют #4772B3. Кнопки, поля и флажки имеют видимые состояния фокуса; настройки сгруппированы в карточки с выровненными колонками и прокруткой при небольшой высоте окна. Ошибки сохранения настроек показываются внутри окна, сохраняя введённый текст. Цвет ошибки — дополнительный семантический токен, не часть исходного руководства.

Системная рамка окна, сообщения Windows и системный выбор папки сохранены. Тема встроена в exe; дополнительные пакеты не нужны. Самопроверка создаёт изображения редактора, настроек, диалога текста и уменьшенного окна настроек в масштабе 150%; они проверены визуально. Проверки инструментов рисования также проходят.

## Название, иконка и папка — v0.4

Отображаемое название, имя exe, свойства файла, заголовки и подсказка трея — «lk Screenshot». В exe встроена иконка в стиле PieMenu и Paint Over: тёмный круг, светлые углы рамки и синий экран. Она используется окнами, треем и ярлыками; ICO включает размеры от 16 до 256 пикселей. Исходный вектор — `assets/logo.svg`, воспроизводимая сборка иконки — `build-icon.ps1`. Основная сборка создаёт exe и ярлык в `dist/v0.4`.

Старые внутренние идентификаторы настроек и проверки единственного экземпляра сохранены для совместимости: папка сохранения и другие настройки не сбрасываются при переименовании.

## Редактор — v0.5

Изображение целиком подгоняется под свободную область окна с сохранением пропорций, без прокрутки. Изменение размера окна меняет только масштаб просмотра; исходное разрешение и координаты аннотаций сохраняются. Текущий цвет выделяется синей подложкой и светлой рамкой. Шесть кнопок инструментов используют встроенные SVG из `assets/icons`; имена доступны через подсказки и средства доступности. Векторная отрисовка работает без дополнительных библиотек.

Проверена подгонка 3840×2160 и 2160×3840, изменение размеров окна, координаты на масштабированном изображении, выбор цвета и прежние проверки рисования. Примеры компоновки в `test-output/editor-large.png`, `editor-small.png`, `editor-portrait.png`.

## Упрощение интерфейса — v0.6

В настройках и редакторе убраны кнопки «Отмена». В редакторе убрана кнопка «Отменить правку», заголовки групп и знак Enter на кнопке сохранения. Размер изображения и подсказки клавиш перенесены вправо в строку инструментов. Ctrl+Z по-прежнему отменяет правку, Enter сохраняет, Esc закрывает редактор. В диалоге ввода текста кнопка отмены сохранена.

## Компактные настройки — v0.7

В редакторе оставлено только разрешение изображения справа сверху; текстовые подсказки и подпись палитры убраны. Иконка размытия — сплошная капля. Настройки размещены на основном фоне без карточек и заголовков групп; строка про PNG и буфер обмена убрана. Кнопка выбора папки находится справа от поля пути. Начальная высота окна подбирается по содержимому без пустого пространства снизу, с ограничением высотой рабочей области экрана.

## Editor v0.15

Mosaic pixelates a selected area using 12-pixel blocks. Crop opens side and corner handles. Drag a border inward to adjust the frame. Switching tools or saving applies the crop, Esc cancels it, and Ctrl+Z restores the previous image. Enter, Ctrl+C and Ctrl+S all save the PNG and copy the image.
