# lk_Screenshot

Утилита для Windows, которая захватывает экран, позволяет редактировать снимок и сохраняет его в PNG. Работает локально и остаётся в системном трее.

## Установка

Скачайте **lk_Screenshot-Setup.exe** на [странице последнего релиза](https://github.com/lee2key/lk_Screenshot/releases/latest). Требуется Windows 11 x64 или Windows 10 x64 версии 1903 и новее со встроенным .NET Framework 4.8 или выше.

Установщик работает без прав администратора. Он добавляет ярлык в меню «Пуск» и предлагает создать ярлык на рабочем столе. Если уже запущена предыдущая версия, завершите её через **Exit** в трее.

## Использование

| Сочетание по умолчанию | Действие |
| --- | --- |
| Print Screen | Выбрать область основного монитора |
| Shift + Print Screen | Снять весь основной монитор |
| Ctrl + Print Screen | Открыть папку снимков |
| Ctrl+S или Ctrl+C в редакторе | Сохранить PNG и скопировать снимок |
| Ctrl+Z | Отменить правку |
| Esc | Отменить текущий ввод, обрезку или закрыть редактор |

- Горячие клавиши для захвата и папки можно изменить в **Settings**. Нажмите на поле сочетания, введите новое и нажмите **Save**. Там же доступны папка снимков, запуск редактора и автозапуск с Windows.
- Снимок включает видимый курсор. Время в имени файла берётся в момент нажатия горячей клавиши. Например, `Screenshot_2026-11-28_02-15.png`.
- В редакторе доступны карандаш, рамка, стрелка, текст, размытие, мозаика и обрезка перетягиванием рамки. Колёсико мыши приближает изображение вокруг указателя.
- В режиме **Text** двойной клик создаёт или открывает надпись. Enter переносит строку. Щелчок по пустому месту завершает ввод, после чего текст можно перетащить. Пока вы печатаете, Ctrl+C копирует выделенный текст, а Ctrl+S сохраняет снимок.
- Если Print Screen занят «Ножницами» Windows или другой программой, назначьте свободное сочетание в настройках.

## Сборка и проверка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
& '.\dist\v0.20\lk_Screenshot.exe' --self-test test-output
```

Для сборки установщика добавьте `-Installer`. Скрипт ищет компилятор Inno Setup 6 (`ISCC.exe`) в PATH и в соседнем проекте `lk_PieMenu`. Можно передать его путь через `-InnoCompiler`. Результат сборки находится в `dist/v0.20`, а отчёт проверки — в `test-output/result.txt`.

Для проверки редактора без захвата экрана запустите exe с аргументом `--editor-demo`. Этот режим сохраняет результат в `demo-result.png`.

Встроенный шрифт Roboto Flex распространяется по [SIL Open Font License](assets/fonts/OFL.txt).
